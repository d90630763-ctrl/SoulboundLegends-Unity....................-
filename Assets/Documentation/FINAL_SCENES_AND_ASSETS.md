# Soulbound Legends — Complete Starter Scene/Asset Package

This package now contains actual Unity scenes for Opening, Character Creation, Lobby, Adventure World/Village 001, Clash/CS, Battle Royale, Siege, Supreme Ruin, and Rift.

Each scene contains a camera/light and a runtime world builder. The runtime builder creates playable prototype geometry, player, NPCs, monsters, bosses, HUD and navigation between scenes.

The package includes the underlying C# systems from the previous final package plus the new scene/runtime layer.

Important: these generated primitive assets are functional starter content, not finished AAA character/terrain models. External art/audio/network credentials/servers are still required for a production release.
