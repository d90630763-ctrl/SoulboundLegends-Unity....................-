- Entity Framework Core 8
- Npgsql PostgreSQL provider

Google:
- Google OpenID Connect discovery and JWKS endpoints

Unity:
- Unity 6000.5 or compatible Unity 6 editor
- Unity's built-in C# runtime/HTTP support
