# SL - Skill VFX Generation & Assembly System

This Unity system connects to a generic Skill System and uses Unity Visual Effect Graph templates to assemble and scale skill visuals.

Features:
- Generic Skill System connection
- Element/form based VFX rules
- Fire, Water, Earth, Air, Lightning, Ice, Nature, Light, Void and Shadow support
- Slash, Projectile, Beam, Explosion, Shockwave, Aura and other forms
- Damage/range/radius/duration/level driven VFX parameters
- Low/Medium/High/Ultra quality scaling
- VFX pooling
- Impact VFX support
- Manual VFX Graph template assignment
- Designed for mobile optimization

Unity 6 / Unity 6000.x with Visual Effect Graph is recommended.

VFX Graph exposed properties supported by default:
SkillLevel, Damage, Range, Radius, Duration, ProjectileSpeed, Color, Intensity.

Gameplay authorization remains the responsibility of the Skill/Server Authorization systems.
