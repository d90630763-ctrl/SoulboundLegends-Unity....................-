# Inspector Setup — Baby Steps

1. Make an empty GameObject named `RiftSystem`.
2. Add `RiftSystemConnectionHub`.
3. Add `RiftSystem`.
4. Create `RiftConfiguration`.
5. Drag the configuration into `RiftSystem`.
6. Drag the same GameObject's `RiftSystemConnectionHub` into `RiftSystem`.
7. On `RiftSystemConnectionHub`, use the list's `+` button to add every compatible provider component from the Combined project.
8. Add the production Server Authority and Server Authorization providers.
9. Add Persistence/Database.
10. Add Adventure World and World Kingdom.
11. Add Quest/Guild.
12. Add Dynamic Instance.
13. Add Monster and Combat.
14. Add Character, Portal and Navigation.
15. Add Destruction.
16. Add Rewards and Progression.
17. Add Anti-Cheat.
18. Add Lore/Discovery, UI, Notifications, Audio and Analytics.
19. Add Live Ops if enabled.
20. Open `SL > Rift > Validate Setup`.

Do not add `RiftLocalTestAuthority` to a production server.
